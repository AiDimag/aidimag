## Why is it free?

aiDimag is **MIT-licensed open source**. The local-first product — CLI, MCP server,
verification, guardrails, IDE extensions, self-hosted sync — is free for any team size,
forever. The project is funded by **[aiDimag Cloud](https://cloud.aidimag.com)**
subscriptions: if you want managed sync without running `dim serve` yourself, that's the
paid product. Self-hosting always remains a first-class, fully supported path.

## FAQ

### Is there a user or team-size limit?

No. MIT license — unlimited users, unlimited repos, commercial use included.

### Does free include the full product?

Yes — every feature (CLI, MCP, verification, guardrails, self-hosted sync, local dashboard). The only thing free does **not** include is the **managed cloud sync** service at cloud.aidimag.com (accounts, hosted sync, billing portal, device approve flow).

### Self-host vs cloud?

| | Self-hosted (free) | aiDimag Cloud |
|---|---|---|
| **Memory** | Local SQLite on each machine | Same — local SQLite |
| **Sync** | You run `dim serve` | We host sync 24/7 |
| **Memory limit** | Unlimited | 100 / 1K / 10K / 50K (by plan) |
| **API keys** | Unlimited | 1 / 1 / 3 / 10 (by plan) |
| **Sync rate** | Unlimited | 1/min (free) or unlimited (paid) |
| **Ops** | Your server, your backups | Managed accounts & billing |
| **Best for** | Full control, air-gapped setups | Teams wanting zero server ops |
| **Pricing** | $0 | $0 / $5 / $15 / $50 per month |

### Can I use it in a commercial product?

Yes — MIT allows commercial use, modification, redistribution, and embedding without restriction.

### How do I get support?

Community support via [GitHub Issues](https://github.com/anup-khanal/aidimag/issues). Cloud subscribers get priority support.
