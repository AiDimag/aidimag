# Download Sample Repo

Want to explore AIDimag hands-on without setting up from scratch? Download our sample repo
with pre-seeded memories, evidence, and a realistic codebase.

## What's included

- A small TypeScript project with `src/db/store.ts`, `src/api/handler.ts`, and `src/payments/` modules
- Pre-seeded AIDimag memory store with 8 memories:
  - **CONVENTION**: All DB access goes through `src/db/store.ts` (with STATIC_CHECK evidence)
  - **GUARDRAIL**: Never call the production API from tests (NEVER level)
  - **FAILED_APPROACH**: Automatic retry on declined payments caused duplicate ledger entries
  - **ARCHITECTURE**: Payment processing uses an idempotency-key-based queue
  - **DECISION**: We use better-sqlite3 instead of Prisma for performance
  - **INVARIANT**: All API handlers must validate input before touching the DB
  - **CONVENTION**: Error responses use `{ error: { code, message } }` format
  - **GOTCHA**: The `payments` table uses cents, not dollars — don't divide by 100
- Git history with a reverted commit (so `dim mine` can detect the FAILED_APPROACH)
- `.aidimag/critical-areas.yml` protecting `src/auth` and `src/payments`
- Pre-generated `CLAUDE.md` context file

## Quick start

```sh
# Download and extract
curl -L https://github.com/AiDimag/aidimag/releases/latest/download/aidimag-sample-repo.tar.gz | tar xz
cd aidimag-sample-repo

# Install AIDimag
npm install -g aidimag

# Explore the memories
dim log

# Run verification
dim verify

# Try a check (stage a change first)
echo 'import Database from "better-sqlite3";' >> src/api/handler.ts
git add -A
dim check --block

# See the health dashboard
dim health

# Start the web UI
dim ui
```

## Or build it yourself

The sample repo is generated by the build script at
[`scripts/build-sample-repo.sh`](https://github.com/AiDimag/aidimag/blob/main/scripts/build-sample-repo.sh)
in the repository. You can run it locally:

```sh
git clone https://github.com/AiDimag/aidimag.git
cd aidimag
bash scripts/build-sample-repo.sh
```

This creates `dist/aidimag-sample-repo.tar.gz` with a fresh memory database and git history.
